# Generation prompt

Use case: stylized-concept

Asset type: production master artwork for a high-resolution real-time strategy
game sprite atlas

Primary request: Create a clean two-part sprite source sheet for an original
late-20th-century desert reconnaissance dune buggy. The left half contains only
the complete buggy chassis with four rugged wheels, low angular armored body,
roll cage, and an empty circular weapon mount; absolutely no gun or turret. The
right half contains only the matching compact swivel-mounted heavy machine-gun
turret as a separate detached component, including its circular mounting base.
Both components point straight toward the top of the image and use exactly the
same scale, camera, materials, and lighting.

Scene/backdrop: perfectly flat uniform solid `#ff00ff` chroma-key background for
background removal; no floor plane.

Style/medium: polished hand-painted RTS unit sprite, crisp realistic military
detail, readable at small size, original design rather than a copy of any
existing game asset.

Composition/framing: strict orthographic 65-degree overhead game camera;
components centered separately in left and right halves with generous
clearance, no overlap, full objects visible, square 1:1 sheet.

Lighting/mood: neutral soft light from upper-left, restrained highlights, no
dramatic lighting.

Color palette: neutral dark graphite and muted olive metal, pale gray removable
paint panels suitable for later team-color tinting; avoid red, magenta, and
bright saturated colors on the objects.

Constraints: one chassis and one detached turret only; chassis has no weapon;
turret is not attached to anything; same north-facing orientation; crisp edges;
no cast shadow, contact shadow, reflection, text, labels, or watermark. The
background must be one uniform `#ff00ff` with no gradient, texture, or lighting
variation. Do not use `#ff00ff` anywhere in the objects.

Avoid: perspective mismatch between the two parts, extra weapons, extra wheels,
duplicate parts, scenery, dust, smoke, insignia, logos, people.

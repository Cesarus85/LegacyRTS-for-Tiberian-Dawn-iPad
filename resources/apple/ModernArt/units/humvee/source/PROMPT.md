# Generation prompt

Use case: stylized-concept

Asset type: production master artwork for a high-resolution real-time strategy
vehicle sprite atlas

Primary request: Create a clean two-part source sheet for an original
late-20th-century light military 4x4 reconnaissance vehicle. The left half
contains only the complete compact four-wheel chassis: angular light armored
utility body, short hood, enclosed two-seat cabin, rugged tires, rear cargo
deck, and an empty circular roof weapon mount; absolutely no gun or turret.
The right half contains only the matching compact swivel-mounted medium
machine-gun turret as a separate detached component, including its circular
roof mounting base. Both parts point toward the top and use the same scale,
camera, materials, and lighting.

Scene/backdrop: perfectly flat uniform `#ff00ff` chroma-key background; no floor
plane.

Style/medium: polished hand-painted RTS unit sprite, crisp realistic military
detail, readable at small size, original generic design rather than a copy of
an existing game asset.

Composition/framing: strict orthographic 65-degree overhead game camera;
components centered separately in left and right halves with generous
clearance, no overlap, complete objects visible, square sheet.

Lighting/mood: neutral soft light from upper-left, restrained highlights.

Color palette: neutral warm gray and muted olive metal, pale gray removable
paint panels suitable for later team-color tinting; no red, magenta, or bright
saturated object colors.

Constraints: one chassis and one detached turret only; same north-facing
orientation; crisp edges; no cast shadow, reflection, text, insignia, people,
or watermark. Uniform key background without gradient or texture.

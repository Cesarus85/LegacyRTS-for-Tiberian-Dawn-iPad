DEINE DATEN BLEIBEN DEINE DATEN

Drei Schritte bis zur ersten Mission

  1. 1

    Gold-CDs bereithalten

    Lege die GDI- und Nod-ISO in Dateien, iCloud Drive oder auf einem USB-Laufwerk ab.

  2. 2

    Gemeinsam auswählen

    Der Systemdialog erlaubt Mehrfachauswahl. Der Import beginnt erst, wenn beide passenden CDs vorliegen.

  3. 3

    Lokal validieren

    Die App prüft und extrahiert auf dem Gerät. ISO-Dateien werden weder hochgeladen noch in der App behalten.

QUELLCODE STATT FERTIGPAKET

Auf dein iPad bauen

Xcode signiert die App mit deinem eigenen Apple-Entwicklerteam. Persönliche Werte bleiben in einer ignorierten lokalen Preset-Datei.

Terminal
# Clone source and dependency
git clone --recurse-submodules YOUR_REPOSITORY_URL
cd legacy-rts-ipad
./scripts/prepare-ipados-dependencies.sh

# Create private signing settings
cp resources/CMakeUserPresets.json.example CMakeUserPresets.json

# Configure and build
cmake --preset ipados-device-local
cmake --build --preset ipados-device-local
open build/ipados-device/VanillaConquer.xcodeproj

FAQ

Vor dem Download wissen

Ist das Spiel enthalten?

Nein. Dieses Repository enthält Portierungsquellcode. Du benötigst eigene, rechtmäßig nutzbare C&C-Gold-Daten für GDI und Nod.

Ist das ein offizielles EA-Projekt?

Nein. Legacy RTS ist ein unabhängiger, deutlich veränderter Community-Port ohne Verbindung, Zustimmung oder Unterstützung durch Electronic Arts.

Läuft Multiplayer?

Derzeit nicht. Der iPad-Build konzentriert sich auf Einzelspieler-Kampagnen und Missionen; Netzwerkcode ist deaktiviert.

Läuft es auch auf macOS?

Der Desktop-Codepfad wird auf macOS auf Kompilierbarkeit geprüft, ist aber ein separates Ziel. Die nativen iPad-Funktionen sind dort nicht automatisch verfügbar; ein öffentlicher macOS-Build benötigt noch einen vollständigen Lauf- und Pakettest.

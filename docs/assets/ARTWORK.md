# Project-page hero artwork

`hero-strategy-collage.jpg` is an original, AI-assisted illustration created
specifically for this independent project page. It does not reproduce original
Command & Conquer packaging, logos, faction marks, characters, or game assets.

The production prompt requested a fictional, insignia-free field commander,
original armored vehicles, and original aircraft in a dramatic retro strategy
illustration. It explicitly excluded Electronic Arts branding, recognizable
Command & Conquer characters and units, copied packaging, and readable text.

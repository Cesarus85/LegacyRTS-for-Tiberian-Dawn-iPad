# Security policy

Please do not open a public issue for a vulnerability that could expose local
files, imported game data, save games, signing information, or device details.

Until a dedicated security contact is published, use GitHub's private security
advisory feature for the repository. Include the affected revision, impact,
reproduction steps, and a minimal test case that contains no original game
data.

There is currently no guarantee of security fixes for unofficial binary builds
distributed by third parties.
